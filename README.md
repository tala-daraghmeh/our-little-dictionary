# 📖 Our Little Dictionary

A small private/shared dictionary built with Flask and SQLite.

This is not a traditional dictionary.

It is a personal collection of words, expressions, and inside jokes that have their own meanings among friends.

## ✨ Features

- Add a new word
- Add an optional note
- View words as individual dictionary pages
- Navigate between pages
- Search for words
- Edit existing words
- Delete words
- Store data using SQLite

## 🛠️ Technologies

- Python
- Flask
- SQLite
- HTML
- CSS
- Bootstrap
- Jinja2
